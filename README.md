# Secure Pull Request Demo — HTML, CSS and JavaScript

This is a small browser calculator used to demonstrate feature branches, pull requests, peer review, branch protection, and automated checks. It does not use Python, a framework, or a database.

## Run locally

Open `index.html` directly in a browser.

## Run tests

If Node.js is installed, run:

```bash
node test.js
node --check app.js
```

## Suggested feature-branch activity

Create a branch named `feature/add-division`, add a division operation to `app.js`, update the HTML dropdown, add a test in `test.js`, and then open a pull request to `main`.
